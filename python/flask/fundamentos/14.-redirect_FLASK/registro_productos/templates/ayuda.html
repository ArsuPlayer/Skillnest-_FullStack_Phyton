Sección de Ayuda y Conceptos

  • Solicitud POST: Envía datos de manera segura desde un formulario hacia el servidor para procesarlos o guardarlos.
  • Solicitud GET: Se encarga de solicitar o recuperar páginas web o recursos desde el servidor sin modificar datos.
  • redirect(): Ordena al navegador del usuario que realice una nueva solicitud HTTP hacia otra ruta (Patrón PRG).
  • request.form: Diccionario que almacena los datos de un POST, pero que no persiste tras una redirección porque esta genera una nueva solicitud GET.
